In `src/components/Nav.astro`, directly AFTER `<slot name="nav-extra" />` (line 207) and before the closing `</ul>`, add one list item:

  `<li><a href="https://realufo.org/" data-external="apex">RealUFO <span aria-hidden="true">↗</span></a></li>`

Decisions (made here, do not re-litigate):
- Label "RealUFO" — matches the apex site's own branding (`<title>RealUFO — ...`, `og:site_name` RealUFO in /Users/laichan/code/tung/realufo-superpower/web/index.html). Existing `text-transform: uppercase` renders it REALUFO ↗, consistent with WAR.GOV / AARO / NASA / NARA.
- ↗ (U+2197) IS used: CLAUDE.md §11 forbids it on INTERNAL header links and explicitly says "Save for explicit external links" — this is a different origin, so the arrow is the correct signal that the user is leaving release.realufo.org. Wrap the glyph in `<span aria-hidden="true">` so screen readers announce "RealUFO" not "RealUFO north east arrow".
- NO `target="_blank"` / `rel="noopener"`: the constraint is "match existing nav external links" and Nav has none; same-tab navigation to a sibling site in the same brand is the simpler, user-expected default. (Footer's `_blank` convention applies to third-party government sources, not our own apex.)
- Placed LAST (after the slot) so page-injected anchors (Headlines / Archive) never render after the external link; order reads: archives → Stories ▾ → About ▾ → page anchors → RealUFO ↗.
- `data-external="apex"` is a stable hook for grep/tests; no JS or CSS consumes it. No new CSS: `nav.primary a` already gives 12 px/14 px vertical padding (44 px+ touch target), full width at <=720 px, and the desktop `<ul>` is `flex-wrap: wrap` so the extra item cannot cause horizontal overflow at any width.
- The existing drawer-close handler (`primaryNav.addEventListener('click', ...)` line 428) uses `closest('a')` and will close the hamburger on tap — no JS change needed.

Also amend the header comment block at lines 18-22 so it no longer claims the nav is internal-only. Replace the sentence "Internal archive-to-archive links only here." with one noting: the single exception is the trailing `RealUFO ↗` link to the apex https://realufo.org/ (different origin — §11 permits ↗ on explicit external links; added quick-261002-0ke). Keep the rest of the comment (the U+2192 "All stories →" note) intact.

Dormant legacy HTML archives (`scripts/copy-legacy-archives.sh`, `scripts/templates/nav.py`) are OUT OF SCOPE — they are not on the active surface and are not re-generated by the Astro build; do not touch them.
